# Options

Every option of the `scan` command, with its key in the configuration file, its type and its default. Run `outskirts help scan` for the help of your version, and see [Configuration](configuration.md) for how the command line and the file combine.

- Every option that takes no value, except `--setup` and `--skip-stdout-results`, also has a `--no-` form, e.g. `--no-strict`.
- Options that take a list accept several values after one flag, e.g. `--exclude-targets A B`; in the file, a single value is read as a list of one.
- Relative paths are resolved from `--project-root`.

This page is generated from [`outskirts.schema.json`](https://github.com/tiny-earth-moon/outskirts/blob/master/outskirts.schema.json), itself generated by `outskirts config schema`.

## Command line only

### `--setup`

Guided setup: detects the project type, asks a few questions, then prints and runs the full scan command. Run it at the project root.

See [Configuration: Command line and file](configuration.md#command-line-and-file).

### `--project-root`

Root directory of the project, from which relative paths are resolved. Default: the current directory.

See [Configuration: The configuration file](configuration.md#the-configuration-file), [Configuration: Command line and file](configuration.md#command-line-and-file), [Configuration: Paths](configuration.md#paths), [Baselines: Options](baselines.md#options).

### `--config`

Configuration file. A relative path is resolved from `--project-root`. Default: `.outskirts.yml`, else `.periphery.yml`, in the project root.

See [Configuration: The configuration file](configuration.md#the-configuration-file), [Configuration: Command line and file](configuration.md#command-line-and-file), [Configuration: Paths](configuration.md#paths).

### `--explain`

Since 3.22.0.

Explains why a declaration is reported, used or retained, before the results. Accepts a name (`draw()`, `draw` or `Beta.draw()`), a USR or a `file:line` location; repeat the option to explain several declarations, e.g. `--explain 'draw()' --explain Sources/Kit/Shape.swift:12`.

See [Troubleshooting: Why a declaration is reported or kept](troubleshooting.md#why-a-declaration-is-reported-or-kept).

### `--summary`

Since 3.22.0.

Prints a summary after the results of the `xcode` format: the count of each result kind, an estimate of the removable lines and the files entirely unused. On by default with `xcode`, `--no-summary` to switch off; with `json`, `--summary` adds a `summary` object to the report. The other formats never hold one.

See [Output formats: Summary](output-formats.md#summary), [Output formats: json](output-formats.md#json).

### `--max-results`

Since 3.22.0.

With `--format agent`, prints at most this many results, a file entirely unused counting all its results; the report then ends with the number of results left out. Scan again after acting on them for the next batch. Default: every result.

See [Output formats: agent](output-formats.md#agent).

## Baselines

### `--baseline`

Baseline file whose entries are hidden from the results.

Key `baseline` · string · default none.

See [Getting started: How a scan works](getting-started.md#how-a-scan-works), [Configuration: Paths](configuration.md#paths), [Baselines: Options](baselines.md#options), [Baselines: Baseline ratchet](baselines.md#baseline-ratchet).

### `--write-baseline`

Write the results to a baseline file, keeping the entries of baseline.

Key `write_baseline` · string · default none.

See [Getting started: How a scan works](getting-started.md#how-a-scan-works), [Configuration: Paths](configuration.md#paths), [Baselines: Options](baselines.md#options), [Baselines: File format](baselines.md#file-format).

### `--prune-baseline`

Rewrite the baseline file keeping only the entries that still match a result; requires baseline.

Key `prune_baseline` · flag, `--no-prune-baseline` to switch off · default `false`.

See [Baselines: Options](baselines.md#options), [Baselines: File format](baselines.md#file-format), [Baselines: Baseline ratchet](baselines.md#baseline-ratchet), [Continuous integration: Baseline ratchet](ci.md#baseline-ratchet).

### `--strict-baseline`

Exit with status 1 if the baseline holds entries that no longer match; requires baseline.

Key `strict_baseline` · flag, `--no-strict-baseline` to switch off · default `false`.

See [Getting started: Exit status](getting-started.md#exit-status), [Baselines: Options](baselines.md#options), [Baselines: Baseline ratchet](baselines.md#baseline-ratchet), [Roadmap: Published](roadmap.md#published).
